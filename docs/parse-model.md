# mascii の AA はこう読まれる(パースのメンタルモデル)

厳密な定義より「絵を見たときにパーサが何を考えるか」を優先した文書。
細部の正確な規則は docs/aa-spec.md、設計の経緯は docs/design.md。

## 大前提

- AA は**ソースコード**。パーサは受理する全ての絵を一意に読み、
  `fmt` がそれを整った正準形に直す。手書きの揺れ(ASCII 文字、余分な
  空白、旧形式)は広く受け付ける。
- **空白は「有る/無い」だけが意味を持つ**。2個と3個で意味が変わる規則は
  存在しない。空白の役割はトークンを切ること(貪欲に読む構造は空白で
  止まる)。
- 打ち消し(U+0338)は文字の後ろに付く結合文字なので、読み込み時に
  「そのセルに斜線フラグ」という形で分離しておく。

## 手順1: 領域の基線を決める

パースの単位は「矩形領域+基線行」。基線が親から分かっていない領域
(分数の分子など)は、**トリム後の左端列**の形で決める:

```
   1          ∞                        ⎛   ⎞      ┌   ┐
 ─────      ┄┄∑┄┄       𝑥̂          ⎜ … ⎟        …
  𝑥+1        𝑛=1        ↑最上段のマーク ⎝   ⎠      └   ┘
 ↑─の行     ↑┄の行       を剥いだ残り   ↑中身で再帰  ↑extent中央
```

- 左端列に `─` `┄` `═` があればその行(範囲行は中身より左に出っ張る)。
- アクセントマークなら上下から剥いで、残った基底の行。
- 縦括弧なら: 波・山括弧は**頂点(⎨ ⟨)の行**をそのまま読む。丸・角括弧や
  `⎸ ▏` は中身に潜って決める(中身が行列なら extent 中央)。
- 格子の縁(`┌ ├ └`)なら extent 中央行。
- `╭` なら下側(引数側)に、`╰` なら上側に潜る。
- どれでもなく非空白行が1つだけならその行。決まらなければ曖昧エラー
  (基線の分かる書き方に直してもらう)。

## 手順2: 基線を左から右へ読む

基線行を走査し、見えた形で分岐する。各構造は自分の列範囲を消費し、
その範囲の上下の矩形へ再帰する。以下「この形を見たら、こう」の一覧。

### 斜線フラグが立っている → 打ち消し

```
 𝑥̸𝑦̸
────  ← ではなく、基線上の 𝑥̸𝑦̸ のような flagged セルのラン
```

フラグ付きセルのランが `\cancel`。途中に空白があっても、その区間が
**全て空白か打ち消し済み**なら1つの打ち消しとして繋がる(最大打ち消し)。
中身は打ち消しモードで普通に再帰する。

### 空白が続く → 直前要素の添え字たち

```
 2      𝑏
𝑥  𝑦   𝑎   ← 基線が空白の列範囲。上にあるものは上付き、下は下付き
        𝑐
```

基線が空白のランは、上側・下側を**別々に**塊へ分割して `^`/`_` にする。
両側とも空白の列は塊の内部(区切りではない)。括弧などの内側は
保護されていて、そこで塊が切れることはない。

ただしランに入る前に2つだけ先読みする:

- ランの中の列に格子の縁 `┌ ├ └` があり、その格子の**中央がこの基線**なら、
  添え字ではなくインラインの裸行列(下記)として切り出す。
- ランの中の列の上に `╭`(下に `╰`)があり、その範囲行の**引数側がこの
  基線を含む**なら overbrace / underbrace として切り出す。

どちらも「基線がその構造の空白部分を通る」せいで走査が素通りしてしまう
形なので、列に必ず現れる予約グリフを目印に拾う。

### `───` → 分数。ただし `──>` は矢印

```
 𝑎+𝑏         𝑓
─────       ──>      ─── >
  2        ↑矢印     ↑分数と原子の >(空白で切る)
```

`─` のランを読み、**直後に `>` が密着していれば**ラベル付き矢印
(上下は over/under ラベル)、そうでなければ分数(上下は分子/分母)。
`═══>` は二重矢印 `⇒`。`<──` `<══` は左向き(`<` の直後が胴体かを
1文字先読み)。密着か空白かだけで決まる。

### `┄` に挟まれた列 → 上下極限つきのバンド

```
  ∞
┄┄∑┄┄ 𝑎ₙ     ┄lim┄ 𝑓(𝑥)     ┄arg┄max┄ 𝑓(𝑥)
 𝑛=1          𝑥→0              𝑥∈𝑆
```

**空白なしで `┄` に挟まれたものは何であれ**バンド=上下に極限を取る。
中身(piece)は複数あってよく(`┄arg┄max┄`)、連結して基底になる。
バンドは空白まで貪欲に読むので、隣の要素とは必ず空白1で切れている。
極限が両方空のバンドは存在しない(裸の `∑` はただの1文字)。

### 縦に伸びた括弧 → デリミタ

```
⎛    1 ⎞     ⎧ 1 ⎫     ╱     1 ╲     ⎸𝑥⎹     ▏…▕
⎜1 + ─ ⎟     ⎨───⎬     ⟨𝑥 + ───⟩     ↑絶対値  ↑ヌル(\left.相当)
⎝    𝑥 ⎠     ⎩ 2 ⎭     ╲     2 ╱
```

読み方は全族共通:

1. 開き列(`(⎛⎜⎝` `[⎡⎢⎣` `{⎨` `⟨` `⎸` `▏` のどれか)を見つけたら、
   基線行を右へ深さ計数して**構造的に対応する閉じ列**を探す。
   左右のグリフは必ず別文字なので、`(0,1]` のような不一致ペアも数えられる。
   両側で同じ文字になる `⎪ ╱ ╲` だけは、その列を縦に辿ってどちら側かを
   確かめる。
2. 内側に**全高の `│` 列**があれば middle: `⟨ψ│H│ψ⟩` `{𝑥│𝑥>0}` のように
   セグメントへ分割する(各セグメントは親と同じ基線)。
3. 波括弧の頂点 `⎨` と山括弧の頂点 `⟨` は必ず基線行に描かれるので、
   これらの列は見ただけで基線が分かる。

### 行列 — デリミタの中の最小マーカー、裸なら格子

```
⎡ 𝑎   𝑏 ⎤      ⎡   ┬   ⎤      ⎡ 𝑎 ⎤      ┌   ┬   ┐
⎢   ┼   ⎥      ⎢ 𝑎   𝑏 ⎥      ┠   ┨        𝑎   𝑏
⎣ 𝑐   𝑑 ⎦      ⎣   ┴   ⎦      ⎣ 𝑏 ⎦      ├   ┼   ┤
 ↑複数×複数      ↑1行           ↑1列         𝑐   𝑑
                                          └   ┴   ┘ ↑裸(\array)
```

デリミタの中に「**空白と `┼` だけの行**」「上端行の `┬`/下端行の `┴`」
「デリミタ列に食い込んだ `┠ ┨`」のどれかが見えたら、中身は1つの行列。
マーカーの位置で行と列を切り、各セルで基線を測り直す。
「マーカー以外が混ざった行」は区切り行とみなさない — 入れ子の行列は
必ず自分の括弧や縁のグリフを同じ行に落とすので、誤検出しない。

裸の行列(括弧なし、\begin{matrix} 相当)は自分で範囲を示す必要が
あるため、外周含む全交点に `┌┬┐ ├┼┤ └┴┘` を置いたフルフレームの格子。
角があるので、隣り合う2つの格子が1つに融合して読まれることはない。

セルの中身やまわりの空白は何桁あっても意味を持たない(境界は常に
マーカーが決める)。

### `╭──╮` / `╰──╯` → overbrace / underbrace

```
  𝑛
╭───╮
 𝑎+𝑏 + 𝑐     ← \overbrace{a+b}^{n} + \underbrace{c}_{m}
      ╰─╯
       𝑚
```

範囲行が引数ブロックに密着し、その先にラベル。分数の罫線を基線の外へ
ずらした形だと思えばよい(幅の規則も分数と同じ)。

### `"…"` と `'…'` → テキスト、それ以外の `'` → prime

```
∫𝑓(𝑥)dx      "if␣x"      '𝑑'?→ 'd'      𝑥''
     ↑裸のラン ↑\text      ↑\mathrm 強制   ↑二重 prime のまま
```

- `"…"` は常に `\text`(引用符内の空白は `␣` で書く)。
- `'` は prime と共用: **閉じ `'` が(空白を跨がず)あって、中身が
  非空の ASCII 英数だけ**のときに限り `\mathrm` の引用。それ以外は prime。
  正準出力では prime が英数字に密着しないよう空白が入るので衝突しない。

### ASCII 英字のラン → 関数か、ローマン体か、変数

ランごと(空白・記号・イタリック文字で切れる極大列)に:

| 見た目 | 読み |
|---|---|
| `sin`(辞書語そのもの) | `\sin` |
| `asiny` `dx`(2文字以上) | `\mathrm{asiny}` `\mathrm{dx}` |
| `a`(単独の1文字) | イタリック変数 𝑎 |
| `d𝑦`(1文字だが文字に密着) | `\mathrm{d}𝑦` |

ラン内の部分マッチはしない(`sinx` は \mathrm{sinx}。\sin x は
`sin x` か `sin𝑥` と書く)。正準形の変数はイタリック体コードポイント
なので、この規則は手書き ASCII のためのもの。

### `√ ∛ ∜` → 累乗根

```
 ____
√𝑥+12      ← オーバーライン `_` の長さが中身の右端。茎 │ は中身の全行
```

### 原子と、その真上/真下 → アクセント

```
^
⇀     ← マークは縦に重なってよい(内側から外側へ)。\hat{\vec{a}}
𝑎
```

原子の真上・真下のセルは他の何にも使われないので、マークが続く限り
縦に読むだけでよい。

### その他

- `⬚` は読み飛ばす(空スロットの表示と、基線の目印)。
- `𝑥² 𝑎ᵢ` のインライン上付き/下付き文字はそのまま `^`/`_`。
- 対応の取れていない `)` などは寛容に原子として読む。

## 手順3: 部分領域へ再帰する

- 親と同じ基線を引き継ぐ: デリミタのセグメント、√ の中身、打ち消しの
  中身、ブレースの引数、バンドの piece。
- 基線を測り直す(手順1へ): 分数の分子分母、バンドの極限、矢印や
  ブレースのラベル、行列のセル、添え字の塊。

## 一意性を支える2つの仕掛け

**保護**: どこかの行で括弧対(格子の縁も含む)の内側にある列は、空白でも
「区切り」として扱わない。入れ子の行列の内部空白が親を分割しない理由。

**レンダラの分離義務**: 密着すると別のトークンに化ける組
(`──`+`──`、バンドと隣接要素、`─`+`>`、英字ラン同士、prime と英数字、
打ち消しのぼろぼろの端)には、正準出力が必ず空白1を入れる。
つまり「貪欲に読んで空白で止まる」だけで読みが一意になるよう、
書く側が距離を保つ。

## 手順4: 正規化 — 同じ絵は同じ AST に

同じ絵になる AST が複数あってはならないので、パース結果は必ず正規形に
落とす: 隣接する同種の添え字は合流(`x^a^b` ≡ `x^{ab}`)、空の
添え字・打ち消し・テキストは消す、極限なしバンドは中身を裸に展開、
入れ子の打ち消しは溶かす、1×1 の行列はただの中身に、行頭行末の
整形スペーサは捨てる。エディタが作るどんな AST も、この正規形を経て
描かれ、描かれた絵はこの文書の読みで元に戻る — それが唯一の契約:

```
parse(render(normalize(x))) == normalize(strip_spacers(normalize(x)))
```
