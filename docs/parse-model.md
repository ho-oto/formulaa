# mascii パースモデル仕様書

AA を「どう読むか」の視点で書いた仕様。`parse.rs` の動作そのものであり、
`render.rs` はこの読みが一意に成立する絵だけを出力する義務を負う
(対応する義務は §9)。ノード別のレイアウト規則は docs/aa-spec.md を参照。

## 0. 契約(何が保証されるか)

AA はソースコードである。要求される不変条件は次の2つだけ:

```
(a) parse は受理する全入力上で決定的(1つの絵に2つの読みがない)
(b) parse(render(normalize(x))) == normalize(strip_spacers(normalize(x)))
    (エディタ内容と整形出力が往復する。整形スペーサだけは再パースで消える)
```

`render(parse(aa)) == aa` は要求**ではない**。受理される絵は正準形より
広く(旧形式・手書き・自由な空白)、`fmt` がそれらを正準形に整える。

**空白の原則**: 空白は「有無」だけが意味を持ち、「個数」に依存する規則は
存在しない。空白はトークンを切る(maximal munch の終端)。

## 1. 前処理: テキスト → グリッド

1. 各行を文字の列に展開し、全行を同じ幅に空白パディングする。タブは空白1。
2. **結合文字の折込**: U+0338 / U+0336(打ち消しオーバーレイ)はセルを
   消費せず、直前セルの「打ち消しフラグ」になる(並行するブールグリッド)。
3. 全体をトリムし、ルート領域として §3 のパースを開始する。

## 2. 予約グリフ(ディスパッチの字母)

以下は構造専用で、原子(`Sym`)としては出現しない。

| 役割 | グリフ |
|---|---|
| 範囲行(基線上) | `─` 分数罫線/単矢印胴体、`┄` バンド、`═` 二重矢印胴体 |
| 範囲行(基線外) | `╭ ╮ ╰ ╯` overbrace/underbrace、`_` √オーバーライン |
| 累乗根 | `√ ∛ ∜` + 茎 `│` |
| デリミタ列 | `⎛⎜⎝ ⎞⎟⎠` `⎡⎢⎣ ⎤⎥⎦` `⎧⎪⎨⎩ ⎫⎪⎬⎭` `⟨⟩╱╲` `⎸ ⎹` `▏ ▕` |
| middle | 全高の `│` 列 |
| 格子 | `┌┬┐ ├┼┤ └┴┘`(裸グリッド)、`┠ ┨`(融合グリッドの接合) |
| 空スロット/基底 | `⬚`(パーサは読み飛ばす) |
| アクセント | 上 `^ ˜ ¯ ⇀ ˙ ¨ ˇ ˘ ˚` / 下 `‗`(原子の `~ →` とは別字) |
| 引用 | `"`(\text)。`'` は prime 原子と共用(§5.7) |
| 表示形 | 数学イタリック体・インライン上付き下付き(原子の描画形) |

`␣`(意味のある空白)、`~`(原子/手書きバンド)、`< >`(比較/矢印先端)、
`'`(prime/引用)は文脈で役割が決まる共用文字。

## 3. 領域と基線

- パースの単位は**矩形領域+基線行**。兄弟ノードは互いに素な列範囲を占める。
- 構造グリフが部分矩形を切り出し、そこへ再帰する。再帰先の基線は
  「親と同じ行」(デリミタ seg、√ の中身、打ち消しの中身)か、
  「改めて復元」(分数の分子分母、極限、格子セル、スクリプト)のいずれか。

## 4. 基線復元(領域の左端列を見る)

基線が与えられていない領域では、トリム後の**左端列**の形で決める:

1. 列に `─` `┄` `═`(手書きは `~` も)があればその行。
   範囲行は基線に載り、内容は中央寄せで両側に余白を持つため左端列を独占する。
2. 上端から上アクセントマーク、下端から下マークを剥ぐ(重ね掛け分繰り返す)。
3. 残った先頭(最上)文字で分岐:
   - `┌ ├ └`(格子の左縁列)→ **extent 中央行**
   - `╭` → 範囲行の下(内容側)を再帰 / `╰` → 上を再帰
   - `⎨` を含む波括弧列・`⟨` を含む山括弧列 → **頂点の行**。
     波括弧列に `⎨` がなく `┠` がある場合(融合グリッドの基線が接合行に
     落ちた形)→ extent 中央行
   - `⎡ [ ⎛ ⎸ ▏` → 対応する閉じ列を上端行で探し、内部が融合グリッド
     (§5.6 のマーカー検出)なら extent 中央行、それ以外は内側を再帰
   - `│ √ ∛ ∜` → 根号の内容領域を再帰
   - `(` → その行
4. 非空白行がただ1つならその行。複数残れば曖昧エラー。

## 5. 基線走査(ディスパッチ)

基線行を左から右へ走査し、文字ごとに以下を**この順で**判定する。
各アームは自分の列範囲を消費し、上下の部分矩形へ再帰する。

### 5.0 打ち消しフラグ(文字より先に見る)

基線セルにフラグが立っていれば `Cancel` の始まり。範囲は
「フラグ付き基線セルのラン」を核に、**全セルが空白または打ち消し済み**の
区間だけを跨いで拡張(最大打ち消し)。範囲内を `in_cancel` で再帰。
全面打ち消しされた格子・ブレース(基線に接地できない構造)は
それぞれのアームが `Cancel` に包んで返し、正規化の隣接合流で繋がる。

### 5.1 空白 → スクリプトラン(先読み付き)

基線が空白のランは原則スクリプト領域(上=上付き、下=下付き)。ただし先に:
- ラン内の列に格子左縁(`┌├└`)があり、その **extent 中央がこの基線**なら
  インラインの裸格子として切り出す(中央が合わない格子はスクリプトの中身)。
- ラン内の列の上に `╭`(下に `╰`)があり、範囲行が閉じていて、かつ
  **引数がこの基線を覆う**なら overbrace/underbrace として切り出す。

スクリプトランの分割(parse_script_run):
- 上側と下側を**独立に**列ラン分割する。境界は「その側が空白 かつ
  反対側が非空白 かつ 非保護」の列(両側とも空白の列は1つの引数の内部)。
- ブラケット保護(§7)された空白列はランを橋渡しする。
- できた塊を左端列順に並べ、`Sup`/`Sub` として出力する。

### 5.2 `┌ ├ └` → 裸格子

左縁列の `┌..└` から行マーカー行を、上端行の `┌┬…┐` から列マーカー列を
読む(`┐` が終端)。全交点のグリフが位置(角/辺/内部)と一致することを検証し、
マーカー間の矩形をセルとして再帰(基線は各セルで復元)。
基線 = extent 中央行。隣接する格子は角が終端を示すため融合しない。

### 5.3 `─` → 分数 or 単矢印(maximal munch)

`─` のランを読み、直後が `>`(または手書きの `→`)なら**ラベル付き矢印**
(op=→)、そうでなければ**分数**。範囲 = ランの列範囲。上下の矩形を再帰
(矢印は over/under ラベル、分数は分子分母)。
`─── >` のように空白を挟めば「分数+原子 `>`」。

### 5.4 `┄` → バンド(上下極限)

文法は `┄+ (piece ┄+)+`。piece は基線1行の平坦な列(空白と `┄` で
区切られる)で、連結して base になる(`┄∑┄` `┄lim┄` `┄arg┄max┄`)。
範囲はラン全体。上=upper、下=lower を再帰し `BigOp{base,lower,upper}`。
バンドは空白まで貪欲に読むため、隣接ノードとは必ず空白1で切れている。

### 5.5 `═` → 二重矢印 / `< ← ⇐` → 左向き矢印

`═` ラン + `>`(`⇒`)で右二重矢印。`<`(`← ⇐`)の直後が `─` なら左単矢印、
`═` なら左二重矢印(1文字先読み)。それ以外の `<` は比較演算子の原子。

### 5.6 デリミタ(open 系グリフ)

基線に現れうる左側グリフ(`( ⎛ ⎜ ⎝ [ ⎡ ⎢ ⎣ { ⎨ ⟨ ⎸ ▏` と、列を辿って
族を解決する `┠`)から開始:

1. **対応探索**: 基線行を深さ計数で走査し、構造的に対応する閉じ列を見つける
   (左右不一致ペア可)。共用グリフ `⎪ ╱ ╲` は列を縦に辿って側を解決する。
2. **縦 extent**: 左列を族グリフで上下に伸ばす。
3. **融合グリッド判定**: 上端行が「空白+`┬`のみ」/下端行が「空白+`┴`のみ」
   /内側の行が「空白+`┼`のみ」/デリミタ列に `┠ ┨` — これらのマーカーが
   1つでもあれば内部は1つのグリッド。マーカーで行・列を分割しセルを再帰、
   `Delim{…, segs=[[Array]]}` を返す(旧形・混在形も同じ経路で受理)。
   「純粋な行」条件が入れ子構造との誤検出を防ぐ(入れ子は必ず他のグリフを
   同じ行に落とす)。
4. そうでなければ **middle 分割**: 内部の全高 `│` 列(非保護)で seg に
   分割し、各 seg を親と同じ基線で再帰。

### 5.7 `"` / `'` → テキスト

- `"…"`: 閉じ引用符までの基線文字列を `\text` として読む(`␣`→空白)。
- `'`: 「閉じ `'` が空白より手前にあり、中身が非空の ASCII 英数/`␣` のみ」
  のときだけ `\mathrm` の引用。それ以外は prime 原子。
  (正準出力は prime を英数・`␣`・引用符から空白1で離すので衝突しない。)

### 5.8 `~` → 手書きバンド or 原子

`~` を胴体とする §5.4 と同じ文法を試し、piece が全て既知の演算子/関数で
上下に極限内容があるときだけバンド。だめなら通常の原子(アクセント探査あり)。

### 5.9 `│ √ ∛ ∜` → 累乗根

茎 `│` を上へ、根号グリフを下へ辿り、オーバーライン `_` の長さで右端界を
決める。中身は親と同じ基線で再帰。

### 5.10 その他

- `⬚` → 読み飛ばし(空スロット・基底アンカー)。
- インライン上付き/下付き文字のラン → `Sup`/`Sub`(打ち消しフラグが
  変わる位置でランを切る)。
- **ASCII 英字のラン**(極大): 辞書語そのもの → `Func`。2文字以上 →
  `\mathrm`(`Text`)。単独1文字 → イタリック変数の原子。ただし前後の
  どちらかが文字(イタリック・ギリシャ含む)に密着していればローマン
  (`d𝑦` の d)。ラン内の部分マッチはしない(`sinx` は mathrm)。
- `)` 等の閉じグリフ単独 → 寛容に原子。
- それ以外 → 原子。直上/直下のセルにアクセントマークがあれば縦に回収して
  `Accent{overs, unders, base}`(内側から外側の順)。

## 6. 再帰先の基線

| 構造 | 部分領域の基線 |
|---|---|
| デリミタ seg・√ の中身・打ち消しの中身・バンド piece | 親と同じ行 |
| 分数の分子分母・バンド極限・矢印ラベル・ブレースのラベル・格子セル・スクリプト塊 | §4 で復元 |
| ブレースの引数 | 親と同じ行 |

## 7. 補助機構

- **ブラケット保護** (protected_cols): いずれかの行でデリミタ対
  (格子の縁 `┌├└`/`┐┤┘`、接合 `┠┨` を含む)の内側にある列は、空白でも
  セル区切り・スクリプト境界として扱わない。深さ計数には `delim_side`
  (共用グリフの側を列walkで解決)を使う。
- **対応探索** (match_delim): side 付き深さ計数。走査行は基線行
  (基線復元の途中では上端行を使う — `⎸ ▏` などは全行が side 判別可能)。
- **アクセント回収** (accent_stacks): 基底の真上/真下をマークが続く限り
  縦に読む。その列は他の何にも使われない。

## 8. 正規化(絵の同値 → 正準 AST)

パーサは読んだ行を必ず normalize してから返す。冪等。

| 規則 | 理由(同じ絵になるため) |
|---|---|
| 隣接する同種 `Sup`/`Sub`/`Cancel` を合流(スペーサ越しも) | 列ランは連続 |
| 空の `Sup`/`Sub`/`Cancel`/`Text` を除去 | 単独 ⬚ は隣と融合する |
| 空極限の `BigOp` は base を行に展開 | バンドなしなら只の並び |
| `Cancel` 内の入れ子 `Cancel` を溶かし、直後の全打ち消しスクリプトを吸収 | 最大打ち消し |
| デリミタ seg の単独 1×1 `Array` を素の行に展開 | 融合形で区別不能 |
| 行頭・行末の `Spacer` を除去 | ⬚基底/打ち消し端スペーサと干渉 |
| 空マークの `Accent` は基底の原子に | マークなしは只の文字 |

## 9. レンダラの分離義務(fuse 表)

正準出力は、隣接すると別のトークンに読める組の間に**空白1**を挿入する
(すべて「有無」の規則。個数規則はない):

| 組 | 誤読 |
|---|---|
| `─`\|`─`、`═`\|`═` | 範囲行ランの融合 |
| `┄` \| 任意(両方向) | バンドが空白まで貪欲に読む |
| `─`\|`>`、`═`\|`>`、`<`\|`─`、`<`\|`═`(手書き矢印グリフ含む) | 矢印化 |
| 英字\|英字(Func/裸 Text の縁) | ラン融合 |
| `'` \| 英数・`␣`・`'`(両方向) | 引用化 |
| 打ち消しの空白縁 \| 次のブロック | 打ち消し範囲の巻き込み |

加えて「打ち消し直後の2Dスクリプト」には空白でなく `⬚` を置く(基線アンカー)。

## 10. 寛容入力のまとめ(正準形に含まれないが受理)

- ASCII 英字(§5.10 の規則で解釈)、`-`≈`−`、`*`≈`∗`、タブ。
- `~` バンド、矢印先端の `→ ← ⇒ ⇐`。
- 旧形の融合グリッド(┬┴+┠┨ 併用)、デリミタで包んだ枠付き裸格子。
- 単独の閉じグリフ(`)` など)を原子として。
- 数学イタリック体ギリシャ文字 → 素のギリシャ文字。

いずれも `fmt` に通すと正準形へ整う。
