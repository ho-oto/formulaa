# 正準AA形式仕様 (Canonical AA Format)

mascii のアスキーアート数式は、AST と**一対一に対応する正準形式**として定義される。
`render.rs`(AST→AA)と `parse.rs`(AA→AST)はこの仕様を両側から実装しており、
**必ず両方を同時に変更**すること。正しさは以下の不変条件で検証される
(`tests/roundtrip.rs`):

```
parse(render(normalize(x))) == normalize(x)   -- 任意の AST x
render(parse(aa)) == aa                        -- 正準 AA
```

## 1. 座標モデル

- 数式は文字のグリッド(全行同幅)。各部分式は**矩形領域 + 基線行**を持つ。
- 兄弟ノードは互いに素な列範囲を占める(`hcat` が基線を揃えて水平連結)。
- パースは「領域と基線を受け取り、基線を左→右に走査して構造グリフごとに
  部分矩形へ再帰する」再帰下降(`parse_region`)。

## 2. 予約グリフ

以下の文字は構造専用であり、原子(`Sym`)として出現してはならない。
シンボル表(`symbols.rs` / `symbols_ext.rs`)からも除外されている。

| グリフ | 用途 |
|---|---|
| `─` U+2500 | 分数罫線(`-` は `−` U+2212 で描画されるため衝突しない) |
| `┄` U+2504 | 大型演算子バンド(極限の範囲標識) |
| `_`(基線より上の行) | √ のオーバーライン(`_` キーは下付きコマンドなので原子化不可) |
| `√ ∛ ∜` | 累乗根(指数 2/3/4)。`│` は根号の縦茎 |
| `⎛⎜⎝ ⎞⎟⎠` | 複数行丸括弧。1行なら `( )` |
| `⎡⎢⎣ ⎤⎥⎦` | 角括弧(行列)。1行なら `[ ]`(キーボードの `[ ]` は予約) |
| `{ } ⎧⎪⎨⎩ ⎫⎪⎬⎭` | 波括弧(頂点 ⎨⎬ は基線行) |
| `⟨ ⟩ ╱ ╲` | 山括弧(腕 ╱╲、頂点は基線行) |
| `⎸ ⎹` U+23B8/9 | 縦棒デリミタ(左/右)。middle は全高 `│` 列 |
| `▏ ▕` U+258F/2595 | ヌルデリミタ(左/右、`\left.` 相当) |
| `┌┬┐ ├┼┤ └┴┘` | 裸グリッドの格子マーカー(区切りの交点。外周を含む) |
| `⬚` U+2B1A | 空スロット・行頭スクリプトの明示基底 |
| `▌` | カーソル(編集ビューのみ。正準形には出現しない) |
| `^ ˜ ¯ ⇀ ˙ ¨ ˇ ˘ ˚` | 上アクセントマーク(原子の `~` `→` とは別コードポイント) |
| `‗` U+2017 | 下アクセントマーク(underline) |
| 数学イタリック体 U+1D434–1D467, `ℎ` | 平文字の描画形(原子は ASCII で保持) |
| `⁰¹²…ⁿⁱ` / `₀₁₂…ₓ` | インライン上付き・下付き |

`␣` U+2423 は予約グリフではなく**通常の原子**(意味のある空白、`\space`。
LaTeX `\ ` / Typst `space`)。これとは別に AST には整形専用の `Spacer`
(Space キー)があり、空白1列として描画されるが LaTeX/Typst には出力されず、
**再パースで消える**: ラウンドトリップ契約は
`parse(render(normalize(x))) == normalize(strip_spacers(normalize(x)))`。
正規化規則: 行頭・行末の Spacer は落とす(行頭スクリプトの ⬚ 基底と
打ち消し端スペーサを守るため)。同種スクリプト間の Spacer はマージで消える。
ブランク区切りグリッドのセル直下には置けない(空白列がセル区切りと衝突)。

## 3. ノード別レイアウト規則

### Sym(原子)
- 英字は数学イタリック体で描画(`a`→`𝑎`, `h`→`ℎ`)。`-`→`−`、`*`→`∗`。
- 自動の間隔調整は一切ない(`x+1`)。見た目の空白はユーザーが整形
  Spacer(実空白1列、再パースで消える)か意味のある `␣` で入れる。

### Func(sin, cos, …)
- 立体(upright)ASCII で描画。平文字がイタリック化されるため、立体英字の
  極大列=関数名として一意にパース可能。辞書は `symbols::FUNCS`。

### Accent(アクセント)
- 基底1文字の**真上**(下マークは真下)のセルにマーク1文字。
- スクリプトは常に基底の右上/右下に置かれるため、原子の直上・直下のセルは
  アクセント以外に使われない → 1セル検査でパース可能。
- 上マークと下マークの文字集合は互いに素。マークの重ね掛けは非対応(エラー)。

### Frac(分数)
- 罫線幅 = max(分子幅, 分母幅) + 2。分子・分母は中央寄せ(両側に必ず1列の
  余白ができるため、領域の左端列には罫線しか現れない)。基線=罫線行。
- 分子・分母領域 = 罫線の列範囲の上下矩形(トリム後、基線は再帰的に決定)。

### Sqrt(累乗根)
- 上段: ` ` + `_`×(引数幅)。以降: 茎(`│`…最下行は `√`/`∛`/`∜`)+ 引数。
- 茎は引数の全行を覆う。オーバーラインの長さが引数の右端界を与える。
- 引数の基線 = 外側の基線と同一行(パース時に再帰不要)。

### Sup / Sub(上付き・下付き)
- 引数が全てインライン化可能な文字なら `x²` `aᵢ` 形式(別コードポイントなので
  無曖昧)。それ以外は 2D ブロックを基線の上/下に右接置。
- **行頭のスクリプトには `⬚` 基底を明示**(`[Sup(x)]` → `⬚ˣ`)。
- パース: 基線が空白の列ラン内で、上側・下側を**独立に**列ラン分割
  (ブラケット保護された空白列はランを橋渡し)、左端列順に並べる。

### BigOp(大型演算子)
- 両極限が空 → 演算子1文字のみ(`∫`)。
- 極限あり → 幅 max(上,下,1)+2 の `┄` バンドを基線に引き、演算子を中央に
  埋め込む(`┄┄∑┄┄`)。極限はバンドの列範囲内に中央寄せ。
- バンド構造は `┄+ 演算子 ┄+`(両側必ず1文字以上)。これが極限の帰属範囲を
  一意にする(バンドがないと ∑ の上に置いた ∫ と、∫ の下に置いた ∑ が
  同一の絵になる — `examples/ambig.rs` 参照)。

### Delim(汎用デリミタ)
`Delim { left, right, mids, segs }`。left/right/mids は**仕様文字**
`( ) [ ] { } ⟨ ⟩ | .`(`.` はヌルデリミタ)。列グリフは高さ h と基線 bl から:

| 仕様 | h=1 | 複数行(上/延長/**基線行**/下) |
|---|---|---|
| `( )` | `( )` | `⎛⎜⎝ ⎞⎟⎠`(基線マークなし) |
| `[ ]` | `[ ]` | `⎡⎢⎣ ⎤⎥⎦`(同上) |
| `{ }` | `{ }` | `⎧⎪⎨⎩ ⎫⎪⎬⎭` — **頂点 ⎨/⎬ は常に基線行**(角より優先) |
| `⟨ ⟩` | `⟨ ⟩` | 腕 `╱ ╲`、**頂点 ⟨/⟩ は常に基線行** |
| `\|` | `⎸ ⎹` | 全行 `⎸`(左)/`⎹`(右) |
| `.` | `▏ ▕` | 全行 `▏`(左)/`▕`(右) — 裸 array の範囲マーカー |

- middle(`\|`)は seg 間の**全高 `│` 列**。segs.len() == mids.len() + 1。
- 左右不一致ペア(`( ]` など)も合法。対応発見は**基線行での深さ計数**
  (基線行には必ず側判別可能なグリフが現れる)。共有グリフ `⎪ ╱ ╲` は
  列を縦に辿って側を解決する(左右不一致ペアを行が横切る場合に必要)。
- 基線: `⎨ ⟨` 系は頂点行から直接。`⎛ ⎸ ▏` 系は内側を再帰、ただし内側が
  グリッド(下記判定)なら extent 中央行。`⎡` は素の `[ ]`(mid なし)なら
  中央行、mid ありは再帰。

### Cancel(打ち消し線)
- 引数ブロックの**全ての非空白セル**に結合ロングソリダス U+0338 を後置
  (`y̸` のように表示)。結合文字はセルを消費しないので列モデルを壊さない
  (パース時に前のセルのフラグへ折り込む。U+0336 も受理)。
- パース: 基線のフラグ付きセルの列ランを核として、「完全に打ち消された
  区間」だけを跨いで拡張(**最大打ち消し**が正準形。打ち消しが部分的な
  スクリプトは隣のノードに属する)。
- 正準形の規則: 入れ子の Cancel は溶かす。隣接する Cancel は合流。Cancel
  直後の「完全に打ち消されたスクリプト」は内部に吸収。**空の Sup/Sub/Cancel
  は正規形に存在しない**(単独の ⬚ が隣のスクリプト塊と融合するため)。
- レンダラ規則: Cancel の基線右端が空白(√のオーバーライン等)なら空白1列、
  Cancel 直後に 2D スクリプトが来る場合は基線アンカー `⬚` を挿入。

### Array(グリッド)と行列
`Array { rows, cols, cells }`。セルは列内で中央寄せ・
行内で基線揃え。基線 = 中央行 `(h-1)/2`。描画形は**置かれる場所で2種類**:

**(a) デリミタ seg の単独ノード** — ブランク区切りボディ(範囲はデリミタが
与える): 列区切り = 空白2列、行区切り = 空白1行。
- 素の `[ ]`(mid なし)の中身は**常に**グリッド(これが行列の絵。中身が
  グリッドでない AST は normalize が 1×1 Array に包む)。
- それ以外のデリミタ内では「内部の全幅空白行」があるときだけグリッドとして
  読む(=複数行グリッドのみ)。1×1 は素の行へ、1×n はセルを `␣` で連結した
  素の行へ正規化する(不動点までループ — 展開が新たな単独 Array を生む
  ことがある)。
- パース分割: 「全高空白列(2列以上・非保護)」「全幅空白行」で分割。
  **ブラケット保護**: いずれかの行でデリミタ対の内側にある列は区切りに
  しない(入れ子構造の内部空白が親を分割しない)。

**(b) それ以外の位置(裸)** — **格子マーカー**: 区切り行・区切り列の交点
(外周を含む)に位置別の box-drawing 交点グリフを置く:
```
┌   ┬   ┐
  a   b
├   ┼   ┤
  c   d
└   ┴   ┘
```
- 角 `┌┐└┘`・辺 `┬┴├┤`・内部 `┼`。明示的な角があるため隣接する格子同士が
  融合して読まれることはない(`┼` のみだと同じ高さの格子2つ+間の内容が
  「セルの多い1つの格子」と同一の絵になる反例があった)。
- 基線 = 格子全体の中央行。左端列(`┌├└`)からパースが開始でき、基線が
  空白のセル行に落ちる場合も列に格子グリフがあることで検出できる。
- 全面打ち消しされた格子は Cancel に包んでパースし、隣接 Cancel の正規化
  合流に任せる(打ち消し範囲スキャンは格子の空白基線に接地できないため)。

## 4. スペーサ規則

レンダラが自動挿入する空白は「そうしないとパースが壊れる」場合**のみ**:
1. 隣接ブロックの基線行末端が**同じバー文字**(`──` または `┄┄`)で接触する
   場合の空白1列(ランの融合防止)。
2. 基線行末端が空白で終わる Cancel ブロックの直後の空白1列(打ち消し範囲
   スキャンが隣の列を巻き込むのを防止)。
3. Cancel 直後に 2D スクリプトが続く場合の `⬚` 基線アンカー1個。

それ以外の無条件マージンは置かない — 行内の全高空白列は「同一基線の兄弟の
区切り」でなければならず、そうでないと外側から見たスクリプト領域の分割が
壊れる(normalize の合流で修復できるのは同一基線の分割だけ)。
見た目のための空白は自動では入れない。ユーザーが明示的な空白原子 `␣` を
置く(§1 予約グリフ参照)。

## 5. 正規形 (normalize)

パーサが返すのは正規形のみ。レンダラも正規形を前提とする。
- 隣接する同種スクリプトの合流: `Sup(a);Sup(b)` → `Sup(a++b)`(絵が同一のため)。
  合流後の引数は再帰的に再正規化(冪等性)。
- 裸の大型演算子記号: `Sym('∑')` → `BigOp{∑, [], []}`。

## 6. 基線復元 (find_baseline)

部分領域の基線は、トリム後の**左端列**から決定する:
1. 列に `─`/`┄`(寛容入力では `~` も)があればその行(罫線・バンドは基線に
   載り、左端列を独占する)。
2. 上端からの上アクセントマーク・下端からの下マークを除去。
3. 残った先頭文字で分岐: `⎡`/`[` → mid なしなら extent 中央行、mid ありは
   第1セグメントから決定。`⎧⎪⎨⎩`/`⟨╱╲` → 頂点(`⎨`/`⟨`)の行。
   `⎛`/`⎸`/`▏` → 第1セグメントから決定(グリッドなら extent 中央行、
   それ以外は再帰)。`┌├└` → 格子 extent の中央行。`(` → その行。
   `│`/`√∛∜` → 内容領域を再帰。
4. 非空白行がただ1つならその行。複数残ればエラー(曖昧)。

## 7. 寛容パース(手書きAA)

正準形に加えて以下を受理する:
- ASCII 英字をイタリック体と同一視(`x+1` が書ける)。立体英字の極大列は
  関数名辞書(貪欲最長一致)を先に消費し、残りは1文字ずつ原子。
- `-` と `−`、`*` と `∗` の同一視。単独の `)` は原子として受理。
- タブは空白1に置換。
- `~` を大型演算子バンド(`┄`)の手書き代替として受理する。条件は
  「`~+ 演算子 ~+` のパターン」「演算子が既知の大型演算子(BIG_OPS)」
  「バンドの上または下に極限内容がある」の全成立。不成立なら `~` は
  通常の原子(前後に空白を置けば必ず原子)。正準出力は常に `┄`。

## 8. 既知の制限(ロードマップは docs/design.md)

- 可変幅アクセント(`\overline{x+y}`, `\underbrace`)は未対応(基底1文字のみ)。
- 縦棒デリミタ(絶対値・ノルム・行列式 `|A|`)は複数行では未対応
  (`│` が根号の茎と衝突するため、専用グリフの導入が必要)。
- アクセントの重ね掛け(`\hat{\dot{x}}`)は非対応。
- `Func` は辞書名のみ(任意の `\operatorname` は往復不可)。
- イタリック OFF 表示(Ctrl+T)は閲覧用であり、正準形式はイタリック固定。
