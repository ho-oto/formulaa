# 正準AA形式仕様 (Canonical AA Format)

mascii のアスキーアート数式は、AST と**一対一に対応する正準形式**として定義される。
`render.rs`(AST→AA)と `parse.rs`(AA→AST)はこの仕様を両側から実装しており、
**必ず両方を同時に変更**すること。正しさは以下の不変条件で検証される
(`tests/roundtrip.rs`):

```
parse(render(normalize(x))) == normalize(x)   -- 任意の AST x
render(parse(aa)) == aa                        -- 正準 AA
```

## 1. 座標モデル

- 数式は文字のグリッド(全行同幅)。各部分式は**矩形領域 + 基線行**を持つ。
- 兄弟ノードは互いに素な列範囲を占める(`hcat` が基線を揃えて水平連結)。
- パースは「領域と基線を受け取り、基線を左→右に走査して構造グリフごとに
  部分矩形へ再帰する」再帰下降(`parse_region`)。

## 2. 予約グリフ

以下の文字は構造専用であり、原子(`Sym`)として出現してはならない。
シンボル表(`symbols.rs` / `symbols_ext.rs`)からも除外されている。

| グリフ | 用途 |
|---|---|
| `─` U+2500 | 分数罫線(`-` は `−` U+2212 で描画されるため衝突しない) |
| `┄` U+2504 | 大型演算子バンド(極限の範囲標識) |
| `_`(基線より上の行) | √ のオーバーライン(`_` キーは下付きコマンドなので原子化不可) |
| `√ ∛ ∜` | 累乗根(指数 2/3/4)。`│` は根号の縦茎 |
| `⎛⎜⎝ ⎞⎟⎠` | 複数行括弧。1行なら `( )` |
| `⎡⎢⎣ ⎤⎥⎦` | 行列括弧。1行なら `[ ]`(キーボードの `[ ]` は予約) |
| `⬚` U+2B1A | 空スロット・行頭スクリプトの明示基底 |
| `▌` | カーソル(編集ビューのみ。正準形には出現しない) |
| `▶` U+25B6 | 任意の基線マーカー(手書き入力用。正準形には出現しない) |
| `^ ˜ ¯ ⇀ ˙ ¨ ˇ ˘ ˚` | 上アクセントマーク(原子の `~` `→` とは別コードポイント) |
| `‗` U+2017 | 下アクセントマーク(underline) |
| 数学イタリック体 U+1D434–1D467, `ℎ` | 平文字の描画形(原子は ASCII で保持) |
| `⁰¹²…ⁿⁱ` / `₀₁₂…ₓ` | インライン上付き・下付き |

## 3. ノード別レイアウト規則

### Sym(原子)
- 英字は数学イタリック体で描画(`a`→`𝑎`, `h`→`ℎ`)。`-`→`−`、`*`→`∗`。
- display モードでは二項演算子・関係子の前後に空白1(`x + 1`)。
  **compact モード**(スクリプト引数・極限・行列セル内)では空白なし(`n=1`)。

### Func(sin, cos, …)
- 立体(upright)ASCII で描画。平文字がイタリック化されるため、立体英字の
  極大列=関数名として一意にパース可能。辞書は `symbols::FUNCS`。

### Accent(アクセント)
- 基底1文字の**真上**(下マークは真下)のセルにマーク1文字。
- スクリプトは常に基底の右上/右下に置かれるため、原子の直上・直下のセルは
  アクセント以外に使われない → 1セル検査でパース可能。
- 上マークと下マークの文字集合は互いに素。マークの重ね掛けは非対応(エラー)。

### Frac(分数)
- 罫線幅 = max(分子幅, 分母幅) + 2。分子・分母は中央寄せ(両側に必ず1列の
  余白ができるため、領域の左端列には罫線しか現れない)。基線=罫線行。
- 分子・分母領域 = 罫線の列範囲の上下矩形(トリム後、基線は再帰的に決定)。

### Sqrt(累乗根)
- 上段: ` ` + `_`×(引数幅)。以降: 茎(`│`…最下行は `√`/`∛`/`∜`)+ 引数。
- 茎は引数の全行を覆う。オーバーラインの長さが引数の右端界を与える。
- 引数の基線 = 外側の基線と同一行(パース時に再帰不要)。

### Sup / Sub(上付き・下付き)
- 引数が全てインライン化可能な文字なら `x²` `aᵢ` 形式(別コードポイントなので
  無曖昧)。それ以外は 2D ブロックを基線の上/下に右接置(compact で描画)。
- **行頭のスクリプトには `⬚` 基底を明示**(`[Sup(x)]` → `⬚ˣ`)。
- パース: 基線が空白の列ラン内で、上側・下側を**独立に**列ラン分割
  (ブラケット保護された空白列はランを橋渡し)、左端列順に並べる。

### BigOp(大型演算子)
- 両極限が空 → 演算子1文字のみ(`∫`)。
- 極限あり → 幅 max(上,下,1)+2 の `┄` バンドを基線に引き、演算子を中央に
  埋め込む(`┄┄∑┄┄`)。極限はバンドの列範囲内に compact で中央寄せ。
- バンド構造は `┄+ 演算子 ┄+`(両側必ず1文字以上)。これが極限の帰属範囲を
  一意にする(バンドがないと ∑ の上に置いた ∫ と、∫ の下に置いた ∑ が
  同一の絵になる — `examples/ambig.rs` 参照)。

### Paren(括弧)
- 内容が1行なら `( )`。複数行なら `⎛⎜⎝ ⎞⎟⎠` を全行に。
- 対応括弧は上端行での深さ計数で発見。基線 = 内側の基線。

### Matrix(行列)
- セルは compact で描画し、列内で中央寄せ・行内で基線揃え。
- **列区切り = 空白2列**、**行区切り = 空白1行**。外周は `⎡⎢⎣ ⎤⎥⎦`
  (全体1行なら `[ ]`)。基線 = 中央行 `(h-1)/2`。
- パース: 内部矩形を「全高空白列(2列以上・非保護)」「全幅空白行」で分割。
  **ブラケット保護**: いずれかの行でブラケット対の内側にある列は区切りに
  しない(入れ子行列の内部空白が親を分割しない)。

## 4. スペーサ規則

隣接ブロックの基線行末端が**同じバー文字**(`──` または `┄┄`)で接触する
場合のみ、空白1列を挿入する。それ以外の無条件マージンは置かない —
行内の全高空白列は「同一基線の兄弟の区切り」でなければならず、そうでないと
外側から見たスクリプト領域の分割が壊れる(normalize の合流で修復できるのは
同一基線の分割だけ)。

## 5. 正規形 (normalize)

パーサが返すのは正規形のみ。レンダラも正規形を前提とする。
- 隣接する同種スクリプトの合流: `Sup(a);Sup(b)` → `Sup(a++b)`(絵が同一のため)。
  合流後の引数は再帰的に再正規化(冪等性)。
- 裸の大型演算子記号: `Sym('∑')` → `BigOp{∑, [], []}`。

## 6. 基線復元 (find_baseline)

部分領域の基線は、トリム後の**左端列**から決定する:
1. 列に `─`/`┄` があればその行(罫線・バンドは基線に載り、左端列を独占する)。
2. 上端からの上アクセントマーク・下端からの下マークを除去。
3. 残った先頭文字で分岐: `⎡`/`[` → ブラケット範囲の中央行。`⎛` → 内側を再帰。
   `(` → その行。`│`/`√∛∜` → 内容領域を再帰。
4. 非空白行がただ1つならその行。複数残ればエラー(曖昧)。

手書き入力では `▶` を1つ置くと基線行を明示できる(パース時に除去)。

## 6.5 互換表示モード(この仕様の対象外)

`GlyphSet::Compat`(F3 / `mascii fmt --compat`)は、Unicode 数式グリフの
幅が揃わないフォント向けの **表示専用** 出力である。ASCII 英字(イタリック化
なし)・box-drawing 構造グリフ・2Dスクリプトのみを使い、極限バンドを持たない
ため本仕様の可逆性保証の対象外。交換・保存には常に正準形式を使うこと。

## 7. 寛容パース(手書きAA)

正準形に加えて以下を受理する:
- ASCII 英字をイタリック体と同一視(`x+1` が書ける)。立体英字の極大列は
  関数名辞書(貪欲最長一致)を先に消費し、残りは1文字ずつ原子。
- `-` と `−`、`*` と `∗` の同一視。単独の `)` は原子として受理。
- タブは空白1に置換。

## 8. 既知の制限(ロードマップは docs/design.md)

- 可変幅アクセント(`\overline{x+y}`, `\underbrace`)は未対応(基底1文字のみ)。
- 縦棒デリミタ(絶対値・ノルム・行列式 `|A|`)は複数行では未対応
  (`│` が根号の茎と衝突するため、専用グリフの導入が必要)。
- アクセントの重ね掛け(`\hat{\dot{x}}`)は非対応。
- `Func` は辞書名のみ(任意の `\operatorname` は往復不可)。
- イタリック OFF 表示(F2)は閲覧用であり、正準形式はイタリック固定。
