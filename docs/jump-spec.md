# ジャンプ仕様書(^G v2)

^G の候補位置決定アルゴリズムの定義。**実装済み**(editor.rs
`start_jump` / `jump_candidates` / `position_coords`)。この文書は
磨き込みの土台であり、§5 のパラメータは実際に触りながら調整する。

## 0. 原則

1. **表示は動かさない。** ラベルは幅ゼロの重ね書き(design.md §33)。
   不可視スロットの実体化だけが例外で、解除後もゴーストとして残す。
2. **1打鍵で近くへ、2打鍵で遠くへ。** どんな場所へも「ラベル1回」
   または「ラベル→再^G→ラベル」の2段階で滑らかに着けることを保証する。
   そのため遠方も密度を落としつつ必ずカバーする。
3. **矢印キーと役割を分担する。** 矢印1回で届く場所にマーカーは要らない。
   マーカーの隣にマーカーを置くのは無駄(密集ペナルティ)。
4. **個数の絶対上限は設けない。** ラベルキーが尽きたらカーソルキー選択
   (§6)で拾えるため、上限ではなく密度で制御する。

## 1. 座標の取得

全カーソル位置の物理座標 (x, y) は、**全候補に幅ゼロマークを付けた
1回のレンダリング**で得る(マークはレイアウトを変えないので、表示と
完全に一致した座標表になる)。`Block.marks` がそのまま座標表になる。

距離はセル座標のマンハッタン距離に行差の重みを掛けたもの:

```
dist(p, q) = W_Y * |y_p - y_q| + |x_p - x_q|      (W_Y = 3)
```

行をまたぐ移動は視覚的にも操作的にも「遠い」ため重くする。

## 2. 候補の全集合とハードフィルタ

候補 = AST の全カーソル位置(全行の全列)から、以下を**除外**したもの:

- **現在のカーソル位置**(そこに居る)。
- **スペース無しで連続する原子ランの内部。** `𝑎𝑏𝑐` の間に割り込む位置は
  マーカー対象にしない(そこへはラン端から矢印で入る)。
  定義: 位置 (row, k) は、row[k-1] と row[k] がともに「幅1の平坦な
  ノード(Sym / インライン添え字)」であるとき内部とみなす。
  Spacer・␣・構造ノードが隣接していればランは切れている。
- **表示に現れない位置**(実体化しない不可視スロットは対象だが、
  実体化コスト(§4)を負う)。

## 3. 優先クラス

上から順に強い。同クラス内は §4 のスコアで選抜する。

| クラス | 対象 | 理由 |
|---|---|---|
| A: 空スロット | 空の行(未入力の分母・極限・セルなど) | 「次に埋める場所」への移動が最頻の操作 |
| B: 祖先の両端 | カーソルを囲む各行(親・祖父…最上位まで)の先頭と末尾 | 「今いる構造の頭/尻へ出る」は頻出の移動。内側の祖先ほど優先 |
| C: グリッドのセル | カーソルが今いるグリッドの各セル末尾。次いで他のグリッドのセル末尾 | 行列・ベクトルは要素間を気軽に行き来したい |
| D: 一般位置 | 残り全部 | 密度制御の対象 |

A〜C は密度ペナルティを**受けない**(常に打つ)。ただし互いに矢印1回で
届く場合(§4 の近接判定)は優先クラスの高い方(同クラスなら近い方)だけ
残す。

## 4. 密度制御(クラス D の選抜)

貪欲法。カーソルからの距離 `d = dist(cursor, p)` の昇順に候補を走査し、
以下を満たすものを採用する:

1. **近接冗長の禁止**: 既採用のマーカー(および現在のカーソル)から
   **矢印1回で届く**位置は捨てる。
   「矢印1回」= 同じ行で |Δcol| ≤ 1、または同じ構造内の隣接フィールド
   (分子⇄分母など vertical() が1回で移る組)。
2. **距離比例の間引き**: 既採用の最近傍マーカーとの距離が
   `max(R_MIN, α · d)` 未満なら捨てる。
   近距離では最小間隔 R_MIN、遠方では距離に比例して疎になる。
   これが「遠くほど頻度が減るがゼロにはならない」を実現する。

この規則の帰結として **2段階移動の保証**がある: 距離 d の目標の近くには
半径 α·d 以内にマーカーがあり、そこへ飛べば目標までの距離は α·d 以下に
縮む。α < 1 なので繰り返せば指数的に収束する(実用上は2回で十分)。

実体化が必要な候補(バンド未満の空極限など)は距離に **C_GHOST** を
加算して評価する(表示を動かすコストの分だけ採用されにくくする。
クラス A は対象外 — 空スロットは常に出す)。

## 5. パラメータ(調整対象)

| 名前 | 初期値 | 意味 |
|---|---|---|
| `W_Y` | 3 | 行差の重み |
| `R_MIN` | 2 | マーカー間の最小距離 |
| `α` | 1/4 | 間引き半径の距離比例係数 |
| `C_GHOST` | 4 | 実体化コスト |

## 6. ラベル割当とカーソルキー選択

- ラベルは**採用順(= スコア順)**に `a s d f …`(JUMP_LABELS)。
  `a` が最有力(最寄りの空スロットか最寄りの位置)。
- ラベルが尽きても候補は捨てない(上限なし)。ラベル無しマーカーは
  無地の印(例: 反転表示のみ)で示す。
- **カーソルキー選択**: ^G 中の矢印キーは「選択中マーカー」を移動する
  (初期選択 = `a`)。移動先は §1 の距離で測ったその方向の最近傍
  マーカー。選択中のマーカーは色を変えて表示し、Enter で確定移動。
  ラベルキーによる即時ジャンプと併用できる。
  Esc はモード解除(現行どおりゴーストを残す)。

## 7. 表示

- ラベルは対象位置の直後のグリフに重ね書き(現行どおり)。
- 選択中マーカーは別色(反転+強調)。
- 実体化スロットは ⬚(現行どおり。解除後はゴースト)。

## 8. 現行実装との差分(移行メモ)

| 現行 | v2 |
|---|---|
| 距離 = walk順(文書順)の序数差 | 距離 = 物理座標(幅ゼロマークの座標表) |
| 等比アンカー列(片側 L, L/2, …)| 距離昇順の貪欲+近接冗長禁止+距離比例間引き |
| 上限 JUMP_MAX = 16 | 上限なし(ラベル61個+無ラベルマーカー) |
| 連続 atom の内部にも候補 | ハードフィルタで除外 |
| ラベルキーのみ | ラベルキー+カーソルキー選択(Enter 確定) |

実装メモ: 座標表 = `position_coords`(全候補に U+F000+idx のプローブ
マークを打った1回レンダー。クリックの逆写像も同じ表を使うため厳密)。
マーカーは `JUMP_RANK_BASE (U+E100) + rank` のランク文字で AST クローン
に挿入され、表示側がラベル/無ラベル/選択ハイライトに復号する。

補足(クラス B): 「祖先の両端」は Tab(インセット脱出)や Home/End と
役割が重なるが、ジャンプは**何段でも一度に**出られる点が違う
(深い入れ子から一気に最上位の行頭へ、など)。
