# mascii

LyX 風の操作感で数式をインタラクティブに編集する TUI エディタ。
数式は Unicode 数式記号を優先したアスキーアートとして描画され、内部表現
(数式 AST)から LaTeX 文字列を常時生成します。

```
               ________
        − 𝑏 ± √𝑏² − 4𝑎𝑐
  𝑥 = ──────────────────
              2𝑎

LaTeX: x=\frac{-b\pm \sqrt{b^{2}-4ac}}{2a}
```

## 起動

```sh
cargo run                 # Ctrl+S で formula.tex に保存
cargo run -- out.tex      # 保存先を指定
cargo run --example demo  # TUI なしでレンダリングのサンプルを表示
```

## キー操作(LyX 風)

| キー | 動作 |
|---|---|
| 英数字・演算子 | そのまま挿入(`-` は −、レンダリングは数学イタリック体) |
| `\` | コマンドミニバッファを開く(`\frac`␣ `\sqrt`␣ `\alpha`␣ など) |
| `^` / `_` | 上付き / 下付きスロットに入る(x² のように可能ならインライン表示) |
| `(` | 自動サイズ括弧に入る / `)` で括弧の外へ |
| `Space` | 現在のインセット(分数・根号など)から抜ける |
| `←` `→` | 構造の中に入り込みながら移動(分子→分母→分数の後ろ) |
| `↑` `↓` | 分子⇄分母、∑ の上限⇄下限を移動 |
| `Backspace` | 直前を削除(中身のある構造には中に入る/空の構造は削除) |
| `Ctrl+S` | LaTeX をファイルに保存 |
| `F2` | 数学イタリック体の表示切替 |
| `Ctrl+Q` / `Ctrl+C` | 終了 |

## コマンド一覧(抜粋)

- 構造: `\frac` `\sqrt`
- 極限付き大型演算子: `\sum` `\prod` `\int` `\oint` `\bigcup` `\bigcap` …
  (挿入直後は下限スロット。`↑` で上限へ、`Space` で本体へ)
- 記号: ギリシャ文字全種(`\alpha`〜`\Omega`)、`\pm` `\times` `\cdot`
  `\infty` `\partial` `\nabla` `\le` `\ne` `\to` `\in` `\subset` `\forall` …
  (`src/symbols.rs` 参照)

## 設計

```
src/ast.rs      数式 AST。すべての編集スロットは Row(ノード列)
src/editor.rs   構造エディタ。カーソル = (Row へのパス, 列) — LyX と同じモデル
src/render.rs   AST → ベースライン付き 2D 文字ブロック(Unicode 数式記号優先)
src/latex.rs    AST → LaTeX 直列化
src/symbols.rs  コマンド名 ⇄ Unicode のシンボル表
src/main.rs     ratatui フロントエンド
```

内部表現は TeX 文字列ではなく AST です。構造編集・2D レンダリング・LaTeX
出力のすべてが AST から導出されるため、「アスキーアートと一対一に対応する
再編集可能な表現」という最終目標への土台になります。
