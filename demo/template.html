キー操作(LyX 風)

    

      

        
a‑z 0‑9 + = < …原子を挿入(表示は数学イタリック体)

        
\frac ␣ / \sqrt ␣分数・根号(\cbrt で ∛)

        
\sum \int \oint …極限つき大型演算子(↑で上限へ)

        
\alpha \bbR \-> \oo記号 4000+(ミニバッファで名前入力)

        
^ / _上付き / 下付き(可能なら x² と表示)

        
( )  ]自動サイズ括弧 / 行列(\matrix)から出る

      

      

        
Spaceいまの構造(分数など)から抜ける

        
← → ↑ ↓構造の中を通り抜けて移動

        
Shift+← →ブロック選択 → \cancel ^ _ ( \frac で包む

        
\hat \vec \bar \dot直前の1文字にアクセント

        
\cancel打ち消し線(選択があれば選択に適用)

        
Backspace削除(構造は中身から / 選択は一括)

      

    

  


  

    エディタ・レンダラ・パーサは
    JuliaMono
    のグリフ幅を前提にした Rust 実装(mascii)。AA は正準形式で、
    パーサに再入力すれば同じ AST に戻ります(往復性はランダム3万ケースで検証)。
